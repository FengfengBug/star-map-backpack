# 星图背包 设计基线

- 文档版本：v1.0（Task 2.0 审查产出）
- 基线日期：2026-11-08
- 代码基线：`b63a3c8`（第一阶段 UI，Task 2.0 未修改业务代码）
- 适用范围：Sprint 2–7 新增或调整的界面、组件与状态
- 现状来源：`src/styles/base.css`、`src/App.css`、`src/components/*.css` 与 1440 / 1280 / 390 宽度截图复核

## 1. 设计原则

1. 深空主题优先：深蓝黑背景、低饱和信息层、蓝 / 青 / 紫为主色，金色只用于重点与终点。
2. 信息优先：星体大小、亮度、连线样式必须对应可解释的数据含义，不做纯装饰性动画。
3. 低炫光：光晕只用于选中、悬停和数据编码，不叠加多层外发光，不引入粒子堆砌或无限动画。
4. 参数由用户确认：界面不得暗示系统替用户决定分值权重或掌握度。
5. 示例与真实数据分离：示例数据必须明确标注“示例数据，参数可编辑”；能力未上线时同时标注开放阶段。
6. 可访问性：键盘可聚焦、焦点可见、支持 `prefers-reduced-motion`，正文与关键信息不使用低于可读阈值的字号与对比度。

### 2.2 星体色与章节语义

| Tone | 色值 | 语义 | 当前章节映射 |
| --- | --- | --- | --- |
| `blue` | `#7eaeff` | 基础结构 | 基础结构 |
| `cyan` | `#63e1da` | 方法、容器、遍历 | 树与查找 |

使用规则：

- 金色属于强调色，单屏示例中只用于少量重点节点与复习完成端点，不用于大面积背景或常规按钮。

- 新增 tone 前先评估数据语义，不得仅为了视觉变化新增颜色。
- 颜色渐变优先使用 `color-mix(in srgb, var(--tone) …)`，保持同一 tone 的透明层次。

### 2.4 对比度审查

以 `--bg-0` 与面板近似色 `#0b1425` 为背景计算（实际面板含渐变与透明度，数值为参考）：

| 前景 | 在 `#040812` 上 | 在 `#0b1425` 上 | 结论 |
| --- | --- | --- | --- |
| `--text` | 17.99:1 | 16.53:1 | 通过 |
| `--text-soft` | 12.29:1 | 11.29:1 | 通过 |
| `--muted` | 6.02:1 | 5.53:1 | 通过普通文本 AA |
| `--muted-2` | 3.63:1 | 3.34:1 | 未达到 4.5:1，却用于 7.5–9.5px 微文字，登记为 B-10 |
| `--star-blue` | 8.95:1 | 8.23:1 | 通过 |
| `--star-gold` | 12.64:1 | 11.62:1 | 通过 |
| `--success` | 12.87:1 | 11.82:1 | 通过 |
| 待复习 `#d6ad68` | 9.57:1 | 8.80:1 | 通过 |

规则：

- 正文、按钮、关键数据目标对比度不低于 4.5:1；大字号标题不低于 3:1。
- `--muted-2` 只能用于非关键元数据；关键说明不得使用该颜色。
- 新增半透明面板时必须复核实际叠色后的对比度。

## 3. 字体基线

### 3.1 字体族

```css

  'Inter', 'Noto Sans SC', 'HarmonyOS Sans SC', 'PingFang SC', 'Microsoft YaHei UI',
  sans-serif;

  'JetBrains Mono', 'SFMono-Regular', 'Cascadia Mono', Consolas, 'Liberation Mono', monospace;
```

## 7. 动效基线

### 7.1 当前实现

| 场景 | 时长 | 缓动 |
| --- | --- | --- |
| 按钮、目录行、控件 hover | 140ms | `ease` |
| 星体标签状态 | 160ms | `ease` |
| 星体透明度 / 滤镜、连线、Toast | 180ms | `ease` / `ease-out` |
| 轨道与选中环缩放 | 220ms | `ease` |
| 初始 / 恢复布局 `fitView` | 420ms | React Flow 默认 |
| 全局减少动效 | 0.01ms | 强制覆盖 |

### 7.2 后续目标

- 卡片、面板与常规交互：200–300ms，`cubic-bezier(0.22, 1, 0.36, 1)`。
- 航线绘制、路径推进：400–600ms，`cubic-bezier(0.22, 1, 0.36, 1)`。
- 新增动效必须可由 `prefers-reduced-motion: reduce` 关闭或缩短。
- 当前 140–180ms 的 `ease` 与目标不一致，登记为 B-11；Task 7.4 统一收敛，Sprint 5.2 的航线动画直接使用目标曲线。

### 7.3 动效边界

- 不做随机漂浮、无限旋转、粒子爆炸、持续闪烁。
- 星图初始 `fitView` 与“恢复布局”是允许的画布过渡。
- Toast 只做一次性进入，不循环。
- 任何新动效不得阻塞点击、拖拽或键盘操作。

## 8. 数据可视化编码

### 8.1 星体

| 维度 | 编码 | 当前规则 |
| --- | --- | --- |
| 大小 | 分值占比 | `scoreShare` 限制在 4–12，线性映射 28–56px，四舍五入 |
| 亮度 | 掌握度 | `0.46 + mastery / 100 × 0.54`，保留两位小数 |
| 颜色 | 章节 / 语义 | blue / cyan / violet / gold |
| 已复习 | 标签圆点 | 3.5px `--success` 圆点 |
| 选中 | 虚线轨道 + 标签强调 | 虚线环、标签边框与底色增强 |

节点盒子 112×104px；星体可视区 68×68px；标签顶部 75px、最大宽度 116px、字号 12px、颜色 `#aebbd2`；选中标签 `#f2f7ff`。

### 8.2 连线

- 父子关系：实线，表达层级。
- 关联关系：虚线，表达弱关联。
- 激活状态：与选中节点相连的边加粗、提高透明度。
- 边不承载方向箭头；当前语义是知识关联，不是流程执行顺序。

### 8.3 图例

图例必须同时解释：

- 尺寸 = 分值占比
- 亮度 = 掌握度
- 拖拽 / 滚轮缩放

键盘操作提示目前缺失，登记为 B-05。

### 8.4 掌握度文案

| 区间 | 文案 |
| --- | --- |
| ≥ 85 | 掌握扎实 |
| 70–84 | 基本熟练 |
| 45–69 | 仍需巩固 |
| < 45 | 优先复习 |

该文案只描述自评掌握度，不构成学习效果承诺。

## 10. 文案与产品边界

必须遵守：

- 不承诺学习效果，不使用“速成”“几小时复习完”“保过”“押题”“期末救命”等话术。
- 统一使用“时间预算下的优先级决策”“可解释取舍”“参数由用户确认”。
- 示例数据必须标注“示例数据，参数可编辑”；编辑能力未上线时同时标注开放阶段。
- “布局自动保存”当前只保存节点坐标，不代表知识点内容自动保存；在文案修正前不得扩大解释。
- AI 只做辅助：建议拆分知识点、生成自测题、翻译算法理由；不得替用户决定分值权重或掌握度。
- 不开发账号系统、后端、云数据库。
