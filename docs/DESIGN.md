# 星图背包 设计基线

- 文档版本：v1.1（UI/UX 重构基线）
- 基线日期：2026-11-09
- 代码基线：轻色 UI/UX 重构
- 适用范围：Sprint 2–7 新增或调整的界面、组件与状态
- 现状来源：`src/styles/base.css`、`src/App.css`、`src/components/*.css` 与 1440 / 1280 / 390 宽度截图复核

## 1. 设计原则

1. 内容优先：以暖白工作台承载课程与知识图，保持清楚的排版、留白和层级。
2. 星点是知识标记：节点尺寸、亮度与连线含义明确；页面背景不使用星尘或宇宙装饰。
3. 材质有边界：Liquid Glass 只用于导航和浮动控件，正文、卡片与编辑内容使用稳定、可读的浅色表面。
4. 动效有阻尼：拖动时反馈直接，释放后短暂、克制地回稳；不使用弹跳、漂浮或无限循环动画。
5. 信息优先：节点大小、亮度、连线样式必须对应可解释的数据含义，不做纯装饰性动画。
6. 参数由用户确认：界面不得暗示系统替用户决定分值权重或掌握度。
7. 示例与真实数据分离：示例数据必须明确标注“示例数据，参数可编辑”；能力未上线时同时标注开放阶段。
8. 可访问性：键盘可聚焦、焦点可见、支持 `prefers-reduced-motion`，正文与关键信息满足可读字号与对比度。

## 参考方向

- Apple 的 Liquid Glass 指南把玻璃材质放在导航和控件层，并建议内容层继续使用常规表面；本项目只在顶栏时钟、画布控件、图例和提示等浮层使用磨砂材质。[Materials](https://developer.apple.com/design/human-interface-guidelines/materials/)
- Linear 的界面刷新文章强调更轻的图标、弱化非活动信息与增加垂直留白；本项目据此减少全大写英文微标签，拉开信息间距并降低非重点元素的装饰强度。[A calmer interface for a product in motion](https://linear.app/now/behind-the-latest-design-refresh)
- 保留星星作为知识节点标记和航线锚点，让主题来自真实内容与关系，而不是背景图案。

## 3. 字体基线

### 3.1 字体族

```css
--font-sans:
  'Inter', 'Noto Sans SC', 'HarmonyOS Sans SC', 'PingFang SC', 'Microsoft YaHei UI',
  sans-serif;
--font-mono:
  'JetBrains Mono', 'SFMono-Regular', 'Cascadia Mono', Consolas, 'Liberation Mono', monospace;
```

- 当前未加载 Web Font，实际使用系统字体回退；Windows 主要落在 Microsoft YaHei UI，macOS 主要落在 PingFang SC。
- 中文标题、正文与微标签使用 sans；数字、时间、百分比使用 mono。
- 不新增第二套装饰字体。

### 3.2 字号阶梯（现状）

| --- | --- | --- |

| 面板主标题 | 17px / 620 | 知识星图、复习航线 |
| 详情标题 | 18px / 620 | 选中知识点标题 |

- 不为单个组件新增半像素字号；现有半像素字号在 Task 7.4 统一收敛。
- 关键交互标签与提示使用 10px 以上字号；低对比元数据不得承载必要信息。

### 3.3 字重与字距

- 当前字重：400、470、500、520、560、580、600、620、650。
- 后续新增 UI 统一使用 400 / 500 / 600 / 650；470、520、560、580、620 视为历史值，不再扩散。
- 中文标题字距 0.01–0.02em；英文 eyebrow 0.15–0.18em；mono 数字字距 -0.02 至 -0.035em。
- 行高：全局 1.5；标题 1.2–1.28；列表 1.3–1.35；长摘要 1.7–1.8。

### 3.4 短标签与 eyebrow

- 以中文短标签为主，使用 10px 以上系统字体；只有确有语境价值的英文缩写才用 mono。
- 不用全大写英文装饰性微标签堆叠层级；标签只辅助定位，不承载唯一信息。

## 7. 动效基线

### 7.1 当前实现

| 场景 | 时长 | 缓动 |
| --- | --- | --- |
| 按钮、目录行、控件状态 | 180ms | `var(--ease-damped)` |
| 按压反馈 | 320ms | `var(--ease-damped)` |
| 节点尺寸与选中环 | 360ms | `var(--ease-damped)` |
| 拖动释放回稳 | 360ms | `var(--ease-damped)` |
| 航线逐段绘制 | 520ms，段间 40ms | `var(--ease-damped)` |
| Toast | 180ms | `ease-out` |
| 初始 / 恢复布局 `fitView` | 420ms | React Flow 默认 |
| 全局减少动效 | 0.01ms | 强制覆盖 |

### 7.2 交互约束

- 新增动效必须可由 `prefers-reduced-motion: reduce` 关闭或缩短。
- 节点拖动时视觉直接跟随指针，释放后 360ms 回稳；拖动期间不插值，减少跟手滞后。

### 7.3 动效边界

- 不做随机漂浮、无限旋转、粒子爆炸、持续闪烁。
- 星图初始 `fitView` 与“恢复布局”是允许的画布过渡。
- Toast 只做一次性进入，不循环。
- 任何新动效不得阻塞点击、拖拽或键盘操作。

## 8. 数据可视化编码

### 8.1 星体

| 维度 | 编码 | 当前规则 |
| --- | --- | --- |
| 大小 | 分值占比 | `scoreShare` 限制在 4–12，线性映射 28–56px，四舍五入 |
| 亮度 | 掌握度 | `0.46 + mastery / 100 × 0.54`，保留两位小数 |
| 颜色 | 章节 / 语义 | blue / cyan / violet / gold |
| 已复习 | 标签圆点 | 3.5px `--success` 圆点 |
| 选中 | 细实线环 + 标签强调 | 细线环、标签边框与底色增强 |

节点盒子 112×104px；节点可视区 68×68px；标签顶部 75px、最大宽度 116px、字号 12px，使用白色实底以保证阅读。

### 8.2 连线

- 父子关系：实线，表达层级。
- 关联关系：虚线，表达弱关联。
- 激活状态：与选中节点相连的边加粗、提高透明度。
- 边不承载方向箭头；当前语义是知识关联，不是流程执行顺序。

### 8.3 图例

图例必须同时解释：

- 尺寸 = 分值占比
- 亮度 = 掌握度
- 拖拽 / 滚轮缩放

键盘操作提示目前缺失，登记为 B-05。

### 8.4 掌握度文案

| 区间 | 文案 |
| --- | --- |
| ≥ 85 | 掌握扎实 |
| 70–84 | 基本熟练 |
| 45–69 | 仍需巩固 |
| < 45 | 优先复习 |

该文案只描述自评掌握度，不构成学习效果承诺。

## 10. 文案与产品边界

必须遵守：

- 不承诺学习效果，不使用“速成”“几小时复习完”“保过”“押题”“期末救命”等话术。
- 统一使用“时间预算下的优先级决策”“可解释取舍”“参数由用户确认”。
- 示例数据必须标注“示例数据，参数可编辑”；编辑能力未上线时同时标注开放阶段。
- “位置自动保存”只保存节点坐标，不代表知识点内容自动保存；不得扩大解释。
- AI 只做辅助：建议拆分知识点、生成自测题、翻译算法理由；不得替用户决定分值权重或掌握度。
- 不开发账号系统、后端、云数据库。
