# 星图背包

把课程笔记转化为可交互的知识星图，通过 0-1 背包算法，在有限复习时间内筛选最值得复习的知识点，并生成可视化复习航线。

当前仓库已完成 **第一阶段：项目初始化与核心界面**、**Sprint 2：Markdown/TXT 笔记导入与示例课程**、**Sprint 3 的节点编辑面板与参数控件（Task 3.1、Task 3.2）**、**Sprint 4 的 0-1 背包纯函数与可解释输出（Task 4.1–Task 4.3）**、**Sprint 5 的预算联动、航线动画、理由与空状态（Task 5.1–Task 5.4）**，以及 **Sprint 6 的工作区持久化、复习状态、动态重排提示、学习记录时间线、分享卡与 Sprint 复盘（截至 Task 6.99）**。项目不包含账号、后端、云数据库或 AI。

## 当前已实现

- 可运行的 React + TypeScript + Vite 项目
- 基于 `@xyflow/react` 的可交互知识星图
- 内置两套示例课程：数据结构与算法（12 个知识点）与计算机组成原理（14 个知识点）
- 示例课程选择器，载入前确认并替换当前星图
- 自定义星体节点与星座边
- 节点拖动、画布缩放与平移
- 节点大小与亮度编码
- 点击节点或目录查看详情
- 节点位置写入 LocalStorage，刷新后恢复
- 点击“编辑”修改标题、摘要、分值占比、预计用时与掌握度，保存后星体尺寸/亮度、目录与详情同步更新
- 分值占比、预计用时与掌握度使用滑块 + 数字输入联动控件，留空保持“待设置”，越界与小数即时提示
- 详情面板支持标记“已复习”与撤销，标记后节点显示绿色勾选并退出本轮航线，但不会自动修改掌握度
- 掌握度支持在详情面板快速调整，必须点击“保存掌握度”确认后才会更新星体亮度
- 掌握度、复习状态或航线参数保存后自动重算；航线成员变化时提示具体原因，并完整列出移出与加入的节点
- 变更提示支持撤销一次，只恢复上一版航线，不回退刚保存的掌握度、复习状态或节点参数；撤销快照不写入 LocalStorage
- 左侧“学习记录”显示本地事件数量，桌面为右侧 Liquid Glass 抽屉，移动端为底部面板，按本地日期分组并支持全部/复习状态/航线变化筛选
- 自动记录标记/撤销已复习、航线成员真实重排与撤销重排，包含时间、节点、变更摘要、完整移出/加入列表及必要的掌握度和用时变化
- 学习记录独立持久化，清空前二次确认且只删除时间线；不保存敏感笔记全文，读取损坏或写入失败时独立降级，不影响星图与复习参数
- 编辑数值时当前星体尺寸/亮度实时预览，取消或切换节点自动还原，其余节点不跟随重渲染
- 示例课程与导入工作区的节点编辑均写入 LocalStorage，刷新或切换工作区后保留
- 载入示例课程、新建空白星图、清空星图、撤销清空、恢复初始布局
- 工作区快照区分示例、导入与空白三种来源，启动时优先恢复有效快照；空白星图刷新后仍保持空白
- 粘贴或上传 Markdown/TXT 笔记，解析预览后确认替换当前星图或追加为新章节
- 空内容、非法格式、超限文件与解析失败均有明确提示
- 示例数据统一标注“示例数据，参数可编辑”
- 纯 TypeScript 0-1 背包算法：按分钟预算选择复习节点，收益 = 分值占比 ×（100 − 掌握度），输出选中/放弃与总收益、总用时
- 每个选中/放弃节点都有结构化理由（code + 参数）与可复现文案，覆盖选中、超预算、待设置、非法参数、掌握度已满与未入选
- 时间预算滑块（0–300 分钟，默认 150 分钟）驱动 0-1 背包重算，选中节点显示航线标记，放弃节点淡化，待设置参数节点保持中性
- 选中节点按算法顺序生成金色复习航线，每段 520ms、段间 40ms 依次点亮；支持动画开关、按钮重播、`prefers-reduced-motion` 与窄屏降级
- 航线区“查看理由”展示选中/放弃理由：桌面为 Liquid Glass 抽屉，移动端为底部面板，支持全部/选中/放弃筛选与面板内滚动
- 点击理由卡片在星图定位并选中对应节点；待设置/非法参数节点使用中性“待设置”标签，不伪装为放弃
- 无知识点、预算为 0、预算不足、参数待处理、掌握度已满与复习池为空均有明确文案和真实下一步；空状态不展示假数据，禁用生成按钮旁始终说明原因
- 空星图提供“导入笔记”和“载入示例”入口，隐藏无效的恢复布局与图例；预算为 0 可一键调到可用的最小步长预算（如 20 分钟）
- 航线区可打开 4:5 暖纸面分享卡，展示复习顺序、时间预算、预计用时、收益及未纳入节点取舍摘要；长航线与未纳入列表自动聚合
- 分享卡预览与导出共用纯 SVG，在本机生成 1080×1350 PNG，不新增导出依赖、不上传笔记或航线，不包含笔记正文与效果承诺
- 分享预览支持键盘焦点管理、导出中与成功/失败提示；无选中航线时禁用入口，导出失败不影响工作区
- 桌面与移动端响应式布局

尚未实现的后续功能包括 AI 能力，目前暂缓评估。导入的知识点分值占比、掌握度与预计用时保持“待设置”，可在右侧详情面板点击“编辑”补充；导入结果保存在本机工作区，刷新后仍会恢复，不会上传。

## 技术栈

- React 19 + TypeScript + Vite
- `@xyflow/react`（React Flow）
- Lucide React
- 原生 CSS / CSS Variables
- LocalStorage
- Vitest（单元测试）

## 本地运行

要求 Node.js `^20.19.0` 或 `>=22.12.0`（Vite 8 的运行要求）。

```bash
npm install
npm run dev
```

开发服务器默认运行在 `http://localhost:5173/`。

```bash
npm run build      # TypeScript 类型检查 + 生产构建
npm run preview    # 预览生产构建
npm run typecheck  # 仅执行类型检查
npm test           # 运行 Vitest 单元测试
```

## 主要组件

| `StarNode` | 根据分值计算尺寸、根据掌握度计算亮度，渲染星体、标签与选中轨道。 |

## 数据模型

每个知识点包含：

```ts
{
  id, title, content,
  parentId, scoreShare, mastery,
  estimatedMinutes, reviewed, position
}
```

示例数据额外包含 `chapterId`、`tone`、`relatedIds`，用于章节归类、星体色调与关联边生成。

星体视觉编码：

- **尺寸**由 `scoreShare` 映射到 28–56px
- **亮度**由 `mastery` 映射，掌握度越高越明亮
- **颜色**按章节分为蓝、青、紫、金四组
- 已复习节点标签旁显示绿色勾选，并从复习航线候选中排除

## 交互与持久化

- 拖动星体调整布局，拖动画布平移，滚轮或控件缩放。
- 点击星体、目录条目或详情中的关联节点，会同步高亮并更新详情。
- 工作区快照存储键：`star-map-backpack:workspace:v1`，包含来源、课程标题、章节、节点、笔记摘要、坐标与预算；最近一次清空备份存储键：`star-map-backpack:workspace-backup:v1`。
- 学习记录独立存储键：`star-map-backpack:learning-records:v1`，不并入工作区快照；清空时间线只删除该键，“清除全部本机数据”会同时删除工作区、备份、学习记录与旧版键。
- 每次拖动结束后，将全部节点坐标写入当前工作区快照；旧坐标键 `star-map-backpack:node-positions:v1` 与旧编辑键 `star-map-backpack:node-edits:v1` 仍兼容读取。
- 详情面板点击“编辑”可修改标题、摘要、分值占比、预计用时与掌握度；标题/摘要必填，分值 1–100、用时 1–600、掌握度 0–100，非法输入被拦截，取消不写入。
- 分值/用时/掌握度支持滑块与数字联动；编辑数值时当前星体立即预览尺寸与亮度，取消编辑或切换节点后还原，保存后才写入。
- 详情面板“本轮复习”可标记或撤销已复习；标记只改变复习状态并退出航线候选，不会自动修改掌握度。掌握度卡片内的“调整”入口需点击“保存掌握度”后才写回并更新星体亮度。
- 掌握度、复习状态或分值/用时保存后自动重算航线；只有选中成员实际变化时才显示重排提示，标题与摘要编辑不会触发。提示不自动消失，可与理由抽屉切换查看。
- “撤销本次重排”只临时恢复上一版航线结果，已保存的节点参数与复习状态保持不变；预算或算法输入再次变化、导入、切换示例、清空或恢复工作区后，旧提示与撤销快照失效。
- 点击左侧“学习记录”打开时间线；复习操作先写复习事件，航线成员实际变化时再写重排事件，撤销重排也会记录。预算拖动、布局拖动、导入、课程切换以及成员未变化的参数保存不会生成伪重排记录。
- 时间线按本地日期和时分展示，支持全部/复习状态/航线变化筛选；记录只包含节点 ID/标题、变更摘要与必要参数，不读取或保存 `KnowledgePoint.content`。
- 清空记录必须确认，且不会修改知识点、掌握度、复习状态、当前航线或笔记；损坏条目会被跳过，存储不可用或写入失败时新记录保留在本次会话并显示独立提示，星图继续使用。
- 节点编辑与复习状态按工作区保存，刷新或切换工作区后保留；示例课程仍兼容 `sample:<courseId>` 命名空间。
- “载入示例课程”打开选择器，确认后替换当前工作区、重置选中并清除已保存坐标；侧栏刷新按钮仅在示例工作区显示。
- “新建空白星图”与“清空星图”都会先写最近一次备份再进入空白态；清空后 10 秒内可撤销，最近一次清空刷新后仍可从空态或“本机数据”恢复。
- 空白星图不会回退示例；导入工作区刷新后仍恢复为导入内容。
- “恢复布局”会保留当前选中节点，恢复当前课程坐标并清除已保存位置；节点编辑不受影响。
- 导入笔记先解析预览，确认时可选择“替换当前星图”或“追加为新章节”；追加会生成新章节与稳定 ID，保留现有节点、参数、选中态与坐标。
- 导入参数保持“待设置”，可在详情面板补充；导入内容保存在本机工作区，不上传。
- 快照损坏时进入恢复对话框并暂停自动保存，可选择恢复上次清空、载入示例或清除数据重新开始；存储写入失败时保留内存状态并在侧栏提示。
- 点击“生成复习航线”按当前算法顺序重播航线动画；关闭“航线动画”开关后，航线以静态完整路径显示，不影响选中/放弃状态。
- 点击“查看理由”打开理由抽屉或底部面板：理由直接来自 `decisions.message`，按算法输入顺序展示选中、放弃与待设置节点，可筛选并在面板内滚动。
- 点击理由卡片会在星图中选中并居中对应节点，桌面预留抽屉宽度避免遮挡，移动端自动收起面板并提示“已定位「节点」”。
- 时间预算可调到 0；预算为 0、低于最短知识点用时、参数待处理或复习池为空时，航线区显示对应状态与下一步。CTA 只执行真实动作（调到可操作预算、定位待设置节点、打开理由或导入/载入示例），不自动修改参数。
- 无知识点时星图不挂载 React Flow，隐藏“恢复布局”和视觉图例，改显示“导入笔记 / 载入示例”；无可用航线时生成按钮禁用，并在按钮下方常驻原因。
- 存储读取包含结构校验与异常兜底，兼容旧坐标数据，损坏数据不会阻塞页面。
- 有选中航线时，点击航线区“分享卡”可预览当前展示结果，包括撤销后临时恢复的航线；卡片使用当前课程、预算、节点顺序、收益与取舍理由，不另算一套结果。
- 点击“下载 PNG”将纯 SVG 序列化，通过 Canvas 在本机生成 1080×1350 图片，不引入第三方导出依赖；长标题截断，选中超过 5 个和未纳入超过 2 个的部分以聚合摘要呈现，待设置/非法参数单独计数。
- 分享卡不读取或导出 `KnowledgePoint.content`，不包含“几小时复习完”等效果承诺，也不把用户参数描述为系统自动决定；导出失败会提示且不影响工作区。下载是否落盘受浏览器权限控制，成功反馈会提示检查下载权限。

## 设计与实现说明

- 浅色工作台承载课程内容；星点只用于知识节点，背景不铺设星尘。Liquid Glass 仅用于导航与浮动控件，拖拽释放使用短促强阻尼回稳。
- 视觉方向参考 [Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials/) 与 [Linear 的界面刷新](https://linear.app/now/behind-the-latest-design-refresh)：保持内容表面清晰、层级克制并给信息留出呼吸空间。
- 组件样式与业务逻辑分离，节点/边转换和存储逻辑位于 `src/utils/`。
- 示例课程通过 `src/data/sampleCourses.ts` 注册表并存：保留数据结构与算法示例，新增计算机组成原理示例，互不覆盖。
- 解析与映射位于 `src/parsers/`：`parseNote` 负责结构解析，`toKnowledgeNodes` 生成节点并按同级相邻关系生成去重关联边；`importedNote` 负责字符/文件/节点数校验、章节生成与课程摘要；全流程不伪造分值、掌握度或时间。
- 导入 UI 仅接受 Markdown/TXT，单文件不超过 200 KB；确认前不写入星图，确认后替换当前星图。
- 当前阶段所有交互均基于真实状态；算法按时间预算实时重算，航线动画可按开关关闭并完整静态显示，不使用假数据伪装功能。
- 已适配 1440、1280 与 390 宽度，并支持 `prefers-reduced-motion`。

## 0-1 背包算法（Sprint 4–5）

- 入口：`planReviewRoute(items, budgetMinutes)`，纯函数，不依赖 React、DOM、LocalStorage 或系统时间。
- 容量：`budgetMinutes` 分钟预算，小数向下取整，负数视为 0。
- 重量：节点 `estimatedMinutes`，必须为正整数。
- 收益：`scoreShare × (100 − mastery)`；掌握度越高，剩余可提升空间越小。
- 参数处理：分值/用时/掌握度任一为“待设置”或非法（分值 ≤ 0、用时非正整数、掌握度超出 0–100）的节点不参与选择，计入 `skippedIds`。
- 取舍：收益并列时优先保留输入顺序靠前的节点，结果可复现。
- 输出：`selectedIds`、`skippedIds`、`totalBenefit`、`totalMinutes`，以及按输入顺序排列的 `decisions`。
- 理由：每个 decision 含 `reason.code`、`reason.params` 与可展示 `message`；`describeReason(reason)` 可由结构化参数复现文案。
- 理由代码：`selected-in-route`（选中）、`skipped-over-budget`（超出预算）、`skipped-no-mastery-gap`（掌握度已满）、`skipped-pending-parameters`（参数待设置）、`skipped-invalid-parameters`（参数非法）、`skipped-not-in-route`（未进入最优组合）。
- 待设置与非法参数理由会列出具体字段与当前值；未入选理由会引用自身收益与选中组合总收益。
- 测试：`npm test` 同时运行边界/理由单测、航线状态与航线边时序测试，以及两套示例课程集成测试；集成测试覆盖预算 0、超预算、全选、复习池过滤、确定性与多档预算，并用暴力枚举校验最优总收益。
- 界面联动：未复习节点构成复习池，滑块预算变化经 200ms 防抖后调用算法；选中节点显示金色航线点，放弃节点淡化，待设置/非法参数节点保持中性。算法结果不写入 LocalStorage，刷新后按当前参数重新计算。
- 动态重排：`planChange.ts` 比较前后 `selectedIds`，只在成员变化时生成提示；展示中的航线与最新自动结果分离，使一次撤销可暂时恢复上一版结果，同时保留当前工作区参数。撤销快照仅在预算与算法输入键不变时有效。
- 航线动画：选中节点按算法顺序用贝塞尔曲线串联，每段 520ms、段间 40ms，缓动为 `cubic-bezier(0.2, 0.72, 0.18, 1)`；点击“生成复习航线”重播，关闭开关后完整静态显示；`prefers-reduced-motion` 下默认关闭，窄屏降低描边宽度。
- 理由展示：`RouteReasonSheet` 直接消费 `routePlan.decisions`，不新增理由规则；选中与放弃理由全部可见，“待设置/非法参数”节点以中性标签展示且不计入放弃数量；点击卡片只改变选中与视图，不改变算法取舍。
